# Security

This workspace only provides source checkout and build coordination. It does not operate the Nuvio service or own the security response for the upstream applications.

Report a vulnerability to the maintainers of the affected upstream repository using that repository's published security policy or private reporting channel. For the self-host backend, review its upstream `SECURITY.md` before deployment. Do not publish secrets, signing keys, API tokens, backend credentials or private user data in issues or commits.

For problems in the bootstrap tooling itself, open an issue in this workspace without including secrets or private repository data.
